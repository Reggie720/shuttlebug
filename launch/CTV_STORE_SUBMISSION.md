## Platform-specific submission blockers
**LG webOS:** Obtain latest actual .ipk artifact, validate appinfo.json including requiredACG, test on compatible LG TV, capture screenshots, complete seller listing and submit using supported PC workflow.
**Roku:** Build a Roku-native SceneGraph/BrightScript channel (web page cannot simply be uploaded as Roku app), integrate approved video/ad SDK, test on Roku hardware, prepare channel artwork, disclosures and certification.
**Google TV / Android TV:** Build Android TV app bundle/APK with TV launcher, D-pad navigation, playback and policy-compliant ads; test on device/emulator; enroll developer and complete Play Console TV release.
**Fire TV:** Validate Android TV-compatible build on Fire TV, meet Amazon store requirements and submit separately.

## Acceptance test matrix (not yet device-tested)
1. Launch with remote only; visible focus on every interactive item.
2. D-pad up/down/left/right, OK/select, Back; modal and player exit.
3. Search using on-screen keyboard; browse Home, TV, Movies, My List.
4. Play/pause, seek, resume and next episode; test buffering and unsupported formats.
5. Test ad break clearly marked unpaid; preserve film position after ad.
6. Check offline/error messages, 16:9 overscan, text legibility, privacy/terms.
7. Confirm every available title has rightsStatus=reviewed and accurate attribution.
8. Verify no test ad code is presented as paid inventory.
